# Collected-data sample

`event_observations.csv` contains all 20 event-collected ON/OFF intervals, joined to their ten location descriptions. It is a view of existing records, not 20 additional observations. IDs and source workbook row references preserve traceability.

ON/OFF endpoints: independently observed on both nights, as confirmed by the team. Installed counts: assumed; road counts estimated using approximate road lengths and fixture spacing, not physically counted. Exact road lengths/spacing measurements were not supplied. The corridor count estimation method is not documented. Working counts and wattage inputs are described separately in the full inventory.

Times carry +05:30 (Asia/Kolkata). OFF is the following morning. Missing timing precision means unknown, not zero. Continuous ON between endpoints is a reconstruction, not a continuous measurement.
